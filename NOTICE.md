This repository and its releases contain no game data: no zones, textures, sounds, scripts or other files from Call
of Duty: Black Ops. The converter reads the files of a copy of the PC game that you own and writes the files the Vita
program needs. The data it ships (`converter/data`) is layout information about the game's files (offsets, file
names, checksums) and the project's own settings, not game content.

Do not share the files the converter makes: they contain Activision's game data. Buy the game; it is on Steam.
